# Stack Guardian

A PR‑native AI security copilot that deeply understands one stack (e.g., Node+TS+AWS or Python+Django+React), specializes in securing AI‑generated code, and maps every finding to India‑specific compliance (DPDP, RBI IT guidelines) with fix suggestions and tests.

Target customers (initial wedge):

•	Indian SaaS startups and fintechs using:

•	Stack A: Node.js + TypeScript + React + AWS (serverless or ECS/EKS)

•	or Stack B: Python + Django/FastAPI + React + Postgres + AWS/GCP

•	Teams already using GitHub, CI (GitHub Actions), and cloud infra as code (Terraform/CDK).

This directly addresses the four opportunity areas you listed.
